# ADR 0003 — R3 受控桌面操作

日期：2026-11-13。目标为 Windows 11 x64，真实硬件交互仍须独立验收。

- 工具固定为 open_app、open_configured_folder、set_volume、get_system_info。
  应用和目录必须由用户在设置中以 ID、名称、完整路径加入；模型只传目标 ID，不能传路径、
  参数或任意命令。设置接口和确认接口仍要求每次启动的本机会话令牌。
- 默认每次确认。用户可禁用工具，或明确选择自动执行已配置白名单；模型文本不能改变该选择。
  确认票据绑定已验证参数，60 秒过期，原子取出保证一次使用，执行时再次校验配置和目标。
- 应用仅允许 .exe，拒绝已知脚本解释器/系统命令入口、网络路径、相对路径和未知参数。
  路径 resolve 后再检查，阻止指向被禁用目标的符号链接。此边界不防御已控制本机账户、
  能替换用户明确配置二进制的攻击者。
- 本地严格短语支持“打开 VS Code”“打开项目目录”“音量设为30%”“查看系统信息”，
  只匹配配置名称/ID，不解析任意后缀或命令。无需 LLM 也可使用这四类操作。
- 调音量通过 Windows Core Audio COM API；打开应用使用参数数组、shell=False；打开目录
  只接受已验证的已有目录。系统信息不包含用户名、主机名、文件正文或个人安排。
- 工具审计只写时间、工具名、成功与耗时，限最近 100 条；不写路径、正文、密钥或全部模型输出。
- 桌面托盘每 700 ms 刷新状态/颜色，支持打开主窗、静音、悬浮窗和自启动切换。
  悬浮窗可以拖动、显示录音状态及停止；关闭主窗隐藏到托盘。
- 自启动默认关闭，用户启用后只写 HKCU Run/SiLing，指向同目录桌面 EXE，启动仍保持静音。
  只对冻结的 Windows 桌面包启用，不把 Python 开发环境注册为启动项。
- Windows 命名 mutex 限定桌面单实例，第二实例聚焦已有窗口；语音进程继续有独立文件锁。
  sidecar 加入 Kill-on-close Job Object，宿主异常终止时由 Windows 关闭其进程树。
  非零退出有界重启 3 次，重启后换会话令牌并保持麦克风释放。

审查与测试：未知工具/路径/额外参数、解释器目标、未配置 ID、音量越界与 bool/字符串、
确认重放、确认前删除目标、拒绝以及无需模型的系统信息均有自动化测试。
真实打开 VS Code、目录、调节用户电脑音量、托盘/悬浮交互需 Windows 本机留证。
