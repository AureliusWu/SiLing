## 断点接续

从默认分支读取最新 CI 与 docs/qa-matrix.md，先复现尚未通过项，再改代码。
不要重建到其他项目仓库，不把 GitHub Artifact 中的源码锁文件丢失或替换成浮动依赖。
最终硬件验收之前，所有构建保持候选状态，不宣传准确率或长期占用达标。
